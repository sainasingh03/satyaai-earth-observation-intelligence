# 🌍 What is SATYAAI?

**SATYAAI** is an AI-powered Earth Observation Intelligence platform designed to make satellite data easier to understand and use.

Instead of requiring users to understand complex GIS tools, satellite bands, raster processing, or programming, SATYAAI allows them to ask questions in **natural language**.

### Example

> "Where has vegetation decreased near river basins in Kerala between 2022 and 2026?"

SATYAAI can transform that question into a spatial analysis workflow involving:

```text
Natural Language
       ↓
Query Understanding
       ↓
Geospatial Interpretation
       ↓
Satellite / Raster Analysis
       ↓
NDVI / NDWI Analysis
       ↓
Change Detection
       ↓
Evidence + Confidence
       ↓
Earth Intelligence Report
